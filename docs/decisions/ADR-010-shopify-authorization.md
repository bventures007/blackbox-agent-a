# ADR-010 Shopify authorization path, API version and polling coverage

**Status:** accepted 2026-10-31 (P0 feasibility check from public documentation; no account used).

- **Authorization path for the pilot:** a merchant-installed *custom app* created in the Shopify admin ("Settings → Apps and sales channels → Develop apps") issues an Admin API access token for that single store without an OAuth redirect; the token is pasted into the local Sources setup and stored encrypted (ADR-008). This is the one documented path that works for a loopback-only application. Public/partner OAuth needs a reachable redirect URL and is deferred.
- **Required scopes:** `read_orders` (orders, line items, transactions, refunds), `read_all_orders` (orders older than 60 days; needs Shopify approval for public apps, available to custom apps), `read_inventory` and `read_locations` (inventory levels), `read_fulfillments`/`read_merchant_managed_fulfillment_orders` (fulfillment orders), `read_returns` (returns and reverse fulfillment dispositions), `read_shopify_payments_payouts` and `read_shopify_payments_disputes` (balance transactions, payouts, disputes). The adapter records the granted scopes from `currentAppInstallation.accessScopes` and disables capabilities whose scope is missing.
- **API version:** GraphQL Admin API `2025-10` is pinned in `packages/application/src/connectors/shopify/version.ts` and in the fixture server. Each capability declares the fields it reads so coverage is explicit.
- **Transport:** outbound polling only (`local_standalone`): initial import by `orders(query: "updated_at:>=…")` cursor pagination, incremental polls every 5 minutes (configurable 1–60) over `updated_at` with 10-minute overlap, nightly reconciliation of open orders. Webhooks are declared unsupported in this mode. Rate limits follow the cost-based throttle (`extensions.cost`) and `Retry-After`.
- **Limits recorded:** historical order access is limited to 60 days without `read_all_orders`; balance transactions do not expose hold reasons or a processing/available split; `ShopifyPaymentsDispute` lacks a booked chargeback-debit posting link. These appear as missing fields in the capability mappings and produce partial answers.
- **Live proof:** blocked_external until an authorized development store token is supplied; the identical pipeline runs against the provider-shaped fixture server (`fixtures/shopify-fixture-server`) for SLICE-01.
