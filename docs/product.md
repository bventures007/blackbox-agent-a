# Blackbox local pilot

The product records commerce observations, their evidence and deterministic business
interpretations in five append-only tracks. One local owner and separately revocable
read-only agents share the same authorized query services. English is the default
interface language; German is required throughout. The unchanged baseline-v14
contracts and acceptance oracle govern delivery. P0–P4 is the complete scope.

Implementation starts with provider-shaped HTTP order and transaction observations,
PostgreSQL durability, Rust projections, SDK MCP and restart verification. The full
question catalogue and interface follow that checkpoint. Synthetic proof is never
reported as provider verification. No model is needed for local calculations.
